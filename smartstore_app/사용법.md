# 스마트스토어 상품 등록 자동화 — 사용법

작업 엑셀에 상품을 적어 두면, 앱이 사진 정리·보정 → (선택) AI 초안 → 판매가 계산·검증 → 상세페이지 조립 → **판매중지 상태로 등록**까지 해 줍니다. 등록된 상품은 검수 화면에서 확인한 뒤 골라서 판매를 시작합니다.

```
[대기 상품 처리 / 예약 실행]
  → 촬영 사진 분리 → 사진 보정 → AI 초안(빈 칸만) → 가공·검증 → 상세페이지 → 등록(판매중지)
  → 엑셀에 결과 기록 → 카카오톡 알림
[검수 대기 탭] 확인 → 판매 시작
```

---

## 1. 설치와 실행

| 파일 (`dist\SmartStoreApp\` 폴더) | 용도 |
|---|---|
| `SmartStoreApp.exe` | 화면 앱. 평소에는 이것만 씁니다 |
| `SmartStoreCli.exe` | 명령줄 도구 (PowerShell에서 실행, [8장](#8-명령줄-smartstorecliexe)) |
| `SmartStoreAuto.exe` | 예약 실행용 (창 없이 실행). 직접 실행할 일은 없습니다 |

- **폴더째로** 옮겨서 쓰세요. exe만 따로 복사하면 실행되지 않습니다.
- 바탕화면 바로가기: `SmartStoreApp.exe` 오른쪽 클릭 → 바로 가기 만들기 → 바탕화면으로 옮기기.
- 다른 PC에서 쓸 때는 [처음 설정](#2-처음-설정-한-번만)을 그 PC에서 다시 하세요. 키·비밀번호는 PC마다 따로 저장됩니다.

## 2. 처음 설정 (한 번만)

1. **설정** 메뉴: 커머스API 애플리케이션 ID·시크릿 입력 → **저장** → **연결 테스트**. 성공하면 카테고리 목록도 받아 옵니다.
   - 커머스API센터에 이 PC의 공인 IP가 등록되어 있어야 합니다. (**내 공인 IP 확인** 버튼으로 확인)
2. **자동화 설정** 메뉴
   - **작업 엑셀**: 기본 `문서\스마트스토어\상품입력.xlsx`. 없으면 **양식 만들기**.
   - **사진 폴더**: 기본 `문서\스마트스토어\상품이미지`.
   - **판매 수수료율 · 판매가 올림 · 끝자리 · 하루 최대 등록 수 · 상품명 금지어**.
   - **분류 매핑** 표: 엑셀 '분류' 칸에 쓸 이름마다 네이버 카테고리, 마진율, 상품명 규칙, 배송·반품·A/S·고시 템플릿, 상세 템플릿을 정합니다. 카테고리ID 칸을 더블클릭하면 카테고리를 찾을 수 있습니다.
   - **설정 저장**을 누르세요.
3. (선택) **AI 초안**: 자동화 설정 → AI 초안 (Claude) → API 키 입력 → **키 확인·저장**.
4. (선택) **카카오톡 알림·예약 실행**: **예약 · 알림** 메뉴 ([7장](#7-예약-실행과-카카오톡-알림)).

## 3. 작업 엑셀 쓰는 법

`상품` 시트 한 줄 = 상품 하나. **상태가 '대기'인 줄만** 처리합니다.

| 칸 | 쓰는 법 |
|---|---|
| 상품코드 | 직접 정하는 고유값 (예: A001). 사진 폴더 이름과 같아야 합니다 |
| 입력방식 | 도매몰 / 촬영 |
| 원본상품명 · 원가 · 재고 · 분류 | 필수. 분류는 드롭다운(분류 매핑에 있는 이름) |
| 옵션 | `색상:베이지,블랙 / 사이즈:S,M,L` |
| 재고 | 숫자 하나, 또는 옵션별 `베이지-S:3, 블랙-M:5` |
| 실측 | `S:어깨40,가슴50,총장60 / M:어깨42,가슴52,총장62` → 상세페이지 사이즈표 |
| 소재 · 세탁 · 브랜드 · 키워드 | 선택 |
| 이미지URL | 도매몰 이미지 주소, 여러 개는 `\|`로 구분 (사진 폴더가 비어 있을 때만 내려받음) |
| 상품명(최종) · 설명(최종) | 비우면 AI 초안 또는 분류의 상품명 규칙으로 채움. **직접 적으면 절대 바꾸지 않음** |
| 상태 · 네이버상품번호 · 결과메시지 | 앱이 기록 |

- 앱이 엑셀에 쓰는 동안 **엑셀을 닫아 두세요**. 열려 있어도 작업은 계속되고, 결과는 다음 실행 때 엑셀에 반영됩니다.
- 실패한 상품은 결과메시지에 사유가 적힙니다. 고친 뒤 상태를 다시 '대기'로 바꾸면 다음 실행 때 처리합니다.

## 4. 사진

가장 쉬운 방법: **자동화 설정 → 사진 보정 → 상품 사진 넣기**

1. 상품코드를 고르거나 새로 입력합니다.
2. 대표(1장) · 추가(최대 9장) · 상세페이지 칸에 사진을 끌어다 놓거나 **파일 추가**로 고릅니다. 목록 안에서 끌거나 ▲▼로 순서를 바꿉니다.
   - 원고 폴더(`01_대표이미지` · `04_추가이미지` · `05_상세페이지\분할`)가 있으면 **원고 폴더 불러오기** 한 번으로 세 칸이 채워집니다.
3. **사진 폴더에 저장** → 아래 규칙대로 이름이 붙어 복사됩니다. 고른 원래 파일은 그대로 둡니다.
   - 이미 사진이 있던 상품이면 기존 사진은 지우지 않고 `원본\_이전_날짜\` 폴더로 옮겨 둡니다.
4. 이미 사진을 넣은 상품을 고칠 때: 상품코드를 고르면 저장된 사진이 세 칸에 불려옵니다(또는 **기존 사진 불러오기**). 순서를 바꾸거나 빼고 더한 뒤 저장합니다.
   - 이미 스토어에 등록된 상품은 사진 폴더만 바뀝니다. 스토어의 사진은 스마트스토어센터에서 바꾸세요.

폴더 규칙 (직접 넣을 때): `상품이미지\{상품코드}\원본\` 에 사진을 넣습니다.

- 이름순 첫 장 = 대표 이미지, 나머지 = 추가 이미지(최대 9장), 파일명에 `detail`이 들어간 사진 = 상세페이지 전용.
- 등록할 때 자동으로 `보정\` 폴더에 1000×1000으로 보정합니다 (회전·밝기·화이트밸런스·용량). **원본은 건드리지 않습니다.**
  완성된 사진이면 작업 엑셀 **사진보정** 칸에 `그대로`를 적어 보정·배경 제거를 건너뜁니다.
- 폰 사진(HEIC)도 됩니다.
- 대표 이미지 배경 제거(흰 배경)는 자동화 설정 → 사진 보정에서 켭니다. 처음 쓸 때 모델(최고 품질 약 970MB)을 내려받습니다.

### 직접 촬영할 때 — QR 카드로 자동 분리

1. **촬영 사진** 메뉴 → 촬영할 상품 체크 → **선택 상품 QR 카드 PDF 만들기** → 인쇄해서 자릅니다.
2. 촬영: **카드를 먼저 한 장** 찍고 → 이어서 그 상품 사진들. 다음 상품도 카드 → 사진.
   - 카드는 화면 폭의 15% 이상 차지하게, 흔들리지 않게 찍으세요.
3. 폰 사진이 OneDrive·구글 드라이브로 PC에 동기화되는 폴더를 **촬영 사진 폴더**에 지정합니다.
4. **지금 사진 분리** (또는 대기 상품 처리·예약 실행 때 자동으로 먼저 분리).
   - 각 사진은 바로 앞에 찍은 카드의 상품 `원본\` 폴더로 **복사**됩니다. 폰·클라우드의 사진은 지우지 않습니다.
   - 카드 없이 찍었거나 카드 뒤 설정한 시간(기본 3시간)이 지난 사진은 `미분류\` 폴더로 갑니다.
   - 카카오톡으로 받은 사진은 촬영 시각이 지워져 순서를 알 수 없으니 쓰지 마세요.

## 5. 등록하기

**자동화 설정** 하단 버튼:

| 버튼 | 하는 일 |
|---|---|
| 대기 상품 검증 미리보기 | API 호출 없이 판매가·옵션·사진·금지어를 검사하고 상세페이지 미리보기를 만듭니다 |
| 대기 상품 처리 | 실제로 등록합니다 (기본: **판매중지**로 등록 → 검수 후 판매) |

- 하루 최대 등록 수를 넘는 상품은 '대기'로 남아 다음 실행 때 처리합니다.
- 스마트스토어에 같은 판매자 상품코드가 이미 있으면 등록하지 않습니다.
- 상품 하나가 실패해도 나머지는 계속 처리합니다.
- 상세페이지 미리보기만 보려면: 자동화 설정 → 상세페이지 → **대기 상품 상세페이지 미리보기**.
- 상세페이지 디자인 바꾸기: **템플릿 폴더 열기** → `기본.html`을 복사해 고친 뒤, 분류 매핑의 '상세 템플릿' 칸에 파일 이름을 적습니다.

### AI 초안 (선택)

- 상품명(최종)·설명(최종)이 **비어 있을 때만** Claude가 사진 2~4장과 엑셀 값을 보고 채웁니다: 상품명 후보 3개, 특징 3~5줄, 검색 태그, 색상.
- 사진으로 확인할 수 없는 소재·효능·원산지는 쓰지 않게 했지만, **반드시 검수하세요.** AI로 채운 상품은 결과메시지와 검수 화면에 "AI 초안 - 검수 필요"가 붙습니다.
- 등록 전에 미리 만들어 보기: 자동화 설정 → **대기 상품 AI 초안 만들기**.
- 다시 보기·다른 후보 고르기: **저장된 AI 초안 보기** (또는 검수 대기 탭의 **AI 초안 보기**). 등록 전 상품이면 고른 후보를 엑셀에 바로 적을 수 있습니다.
- 비용: 상품 1건에 약 70~80원(사진 4장 기준). 상품마다 한 번만 호출하고 결과를 보관합니다. 검증 미리보기는 API를 부르지 않습니다.
- 키가 없거나 크레딧이 부족하면 AI 단계만 건너뛰고 분류 규칙 상품명으로 등록합니다.

## 6. 검수 후 판매 시작

**상품 관리 → 검수 대기** 탭

1. 사진·상품명·판매가를 확인합니다. 행을 더블클릭하면 등록한 상세페이지를 엽니다.
2. 고칠 게 있으면 행을 고르고 **선택 상품 수정** → 상품명·판매가·재고(옵션별 추가금액·재고·사용)를 고쳐 **저장**합니다. 스마트스토어에 바로 반영되고, 상품은 판매중지 상태 그대로 검수 목록에 남습니다.
   - 잘못 올라간 상품은 체크 → **선택 상품 삭제** → 스마트스토어에서 지우고 검수 목록에서 뺍니다. **되돌릴 수 없습니다.** 엑셀 상태는 '삭제됨'이 됩니다.
   - 지운 상품은 **삭제 내역** 탭에 남습니다. 체크 → **선택 상품 다시 등록**으로 작업 엑셀 줄과 사진 폴더 그대로 판매중지로 다시 올립니다(새 상품번호). 엑셀에서 줄을 지운 상품은 다시 등록할 수 없고, **내역에서 지우기**로 목록에서만 치울 수 있습니다.
3. 판매할 상품을 체크 → **선택 상품 판매 시작** → 판매중 + 전시중으로 바뀝니다.
   - '판매 시작할 때 네이버쇼핑에도 노출'을 켜 두면 네이버쇼핑에도 노출됩니다.
4. 엑셀 상태가 '판매중'으로 바뀝니다.

판매 중인 상품의 수정은 **상품 관리 → 스토어 전체 상품** 탭에서 합니다 (상품명도 고칠 수 있음).
같은 탭에서 여러 상품을 골라 **선택 상품 판매중으로 / 판매중지로**, **선택 상품 품절 처리**(재고를 모두 0으로 → 네이버가 '품절'로 바꿈)를 할 수 있습니다. 품절 상품을 다시 팔 때는 **수정**에서 재고를 넣고, 판매중으로 돌아오지 않으면 **선택 상품 판매중으로**를 누릅니다.
사진·상세페이지·옵션 추가/삭제는 앱에서 고칠 수 없으니 스마트스토어센터에서 직접 고치세요.

## 7. 예약 실행과 카카오톡 알림

**예약 · 알림** 메뉴

- **예약 실행**: 시각(예: 10:00, 18:00)을 추가하고 **예약 등록·갱신**을 누르면 Windows 작업 스케줄러가 그 시각에 '대기 상품 처리'를 창 없이 실행합니다. PC가 꺼져 있었다면 켜진 뒤 실행합니다.
- **카카오톡 알림**: REST API 키 입력 → **키 저장** → **카카오 로그인 연결** → **테스트 메시지 보내기**. 끝나면 "등록 8건 / 실패 1건 / 검수 대기 12건" 같은 요약이 '나에게 보내기'로 옵니다.
  - 연결이 끊겼다는 알림이 오면 같은 화면에서 다시 연결하세요.

## 8. 명령줄 (SmartStoreCli.exe)

PowerShell에서 `dist\SmartStoreApp` 폴더로 이동한 뒤 실행합니다. (개발 환경에서는 `..\.venv\Scripts\python.exe cli.py ...`)

```bash
.\SmartStoreCli.exe run --dry-run
```

| 명령 | 하는 일 |
|---|---|
| `run` | 대기 상품 등록. `--dry-run` 검증만, `--codes A001,A002` 특정 상품만, `--notify` 끝나면 카카오톡 |
| `draft` | AI 초안. `--code A001` 특정 상품, `--force` 다시 만들기, `--set-key` 키 저장 |
| `publish` | 검수 대기 목록. `--codes A001,A002` 또는 `--all`로 판매 시작 |
| `sort-photos` | 촬영 사진 분리 (`--inbox 폴더`) |
| `qr-cards` | QR 카드 PDF (`--codes`, `--out`, `--open`) |
| `process-images` | 사진 보정만 (`--code`, `--all`) |
| `preview` | 상세페이지 미리보기 (`--code`, `--no-process`, `--open`) |
| `schedule` | 예약 조회·등록·해제 (`--times 10:00,18:00 --install`, `--remove`, `--run-now`) |
| `kakao-login` · `kakao-test` | 카카오톡 연결·테스트 |
| `init-template` | 작업 엑셀 양식 만들기 |
| `log` | 최근 실행 내역 |

종료 코드: 0 정상 / 1 실패한 상품 있음 / 2 실행 오류.

## 9. 데이터와 보안

| 무엇 | 어디 |
|---|---|
| 작업 엑셀·사진 | `문서\스마트스토어\` (설정에서 바꿀 수 있음) |
| 앱 DB·로그·상세페이지 미리보기 | `%LOCALAPPDATA%\SmartStoreApp\` (app.db, app.log) |
| 커머스API 시크릿, Claude API 키, 카카오 키·토큰 | Windows 자격 증명 관리자 (`smartstore_app`) — 파일·로그에 남기지 않음 |

- 백업할 것: `문서\스마트스토어\` 폴더와 `%LOCALAPPDATA%\SmartStoreApp\app.db`.

## 10. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "작업 엑셀이 열려 있음" | 엑셀을 닫으세요. 결과는 DB에 보관되어 다음 실행 때 반영됩니다 |
| "이미 실행 중인 작업이 있습니다" | 예약 실행이 돌고 있을 수 있습니다. 잠시 뒤 다시 하세요 |
| 사진이 '미분류'로 감 | 카드를 먼저 찍었는지, 카드 뒤 시간이 너무 지나지 않았는지 확인 → 해당 상품 `원본\`으로 직접 옮기기 |
| QR 카드를 못 읽음 | 카드를 더 크게(화면 폭 15% 이상), 덜 기울여서, 흔들림 없이 다시 찍기 |
| "Claude API 크레딧이 부족합니다" | console.anthropic.com → Plans & Billing에서 충전 |
| 카카오톡 "재연결 필요" | 예약 · 알림 → 카카오 로그인 다시 연결 |
| 등록 실패 사유가 이해되지 않음 | 엑셀 결과메시지와 `%LOCALAPPDATA%\SmartStoreApp\app.log` 확인 |
| 예약 실행이 안 됨 | 예약 · 알림에서 상태(마지막 실행 결과) 확인. exe 폴더를 옮겼다면 **예약 등록·갱신**을 다시 누르기 |
